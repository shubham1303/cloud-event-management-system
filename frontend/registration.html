Submit a simple form to reserve your spot or express interest. This static form can be later integrated with a backend or form service if needed.

Submit a new event idea

If you would like to suggest a new event for the iSchool community, you can use the same form and mention it in the notes section.

  • Briefly describe the topic and format.
  • Mention potential speakers or collaborators.
  • Suggest a target audience and timing.

This project focuses on front-end static pages. In a production setup, the form could be connected to AWS services such as API Gateway, Lambda, and DynamoDB for full workflow automation.
